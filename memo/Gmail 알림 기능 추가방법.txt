[Gmail 알림 기능 추가방법]
제이님, 현재 사생 사이트만 배포(`Streamlit Cloud`)되어 있고 관리자 사이트는 로컬(내 컴퓨터)에서 돌리고 계신 상황에 딱 맞춰서 안내해 드릴게요.

가장 먼저 하셔야 할 일은 **"시스템이 대신 메일을 보낼 발송자 계정"의 앱 비밀번호를 1개 발급받고, 양쪽 환경(배포 클라우드 + 내 컴퓨터 로컬)에 등록**하는 것입니다.

---

### Step 1. 발송용 Gmail 계정의 '앱 비밀번호' 발급 (최초 1회만)

사생들에게 메일을 쏴줄 구글 계정(개인 계정 또는 자치회 공용 계정)에서 진행합니다.

1. [Google 계정 관리](https://myaccount.google.com/) 접속 $\rightarrow$ **보안** 탭 클릭
2. '2단계 인증'이 켜져 있는지 확인 (꺼져 있다면 먼저 활성화)
3. 2단계 인증 메뉴 안쪽(또는 보안 검색창)에서 **'앱 비밀번호'** 검색 후 클릭
4. 앱 이름에 `생활관 대여 시스템` 입력 후 **[만들기]** 클릭
5. 화면에 나타나는 **16자리 영문 비밀번호**(예: `abcd efgh ijkl mnop`)를 복사해 둡니다. *(띄어쓰기 없이 붙여서 사용)*

---

### Step 2. 인증 정보를 클라우드와 로컬에 등록

#### 1) 배포된 사생 사이트 (`Streamlit Cloud`)

사생이 신청서를 제출하면 클라우드 서버에서 사생과 관리자에게 즉시 알림 메일을 보내야 하므로 클라우드 설정에 넣어줍니다.

1. [Streamlit Community Cloud](https://share.streamlit.io/) 대시보드 접속
2. 배포된 사생 앱(`student_app.py`) 우측의 점 세 개(`⋮`) $\rightarrow$ **Settings** 클릭
3. 좌측 **Secrets** 탭 선택
4. 기존에 있던 GCP 설정 아래에 다음 내용을 덧붙여 넣고 **[Save]**:

```toml
[smtp]
sender_email = "발송용구글계정@gmail.com"
app_password = "복사해둔16자리앱비밀번호"
server = "smtp.gmail.com"
port = 465
admin_email = "신청알림받을관리자메일@gmail.com"

```

#### 2) 로컬에서 실행하는 관리자 사이트 (`내 컴퓨터 VS Code`)

관리자 사이트는 로컬에서 실행 중이므로, 나중에 관리자가 [승인]이나 [반려] 버튼을 눌렀을 때 내 컴퓨터에서 사생에게 메일이 발송되려면 로컬 환경에도 똑같은 설정이 필요합니다.

1. VS Code에서 프로젝트 폴더를 엽니다.
2. `.streamlit` 폴더 안에 **`secrets.toml`** 파일이 있는지 확인합니다. (없다면 `.streamlit` 폴더를 만들고 그 안에 `secrets.toml` 생성)
3. 위에서 작성한 `[smtp]` 내용을 그대로 복사해서 `secrets.toml` 파일에 저장합니다.
*(※ `.gitignore`에 `.streamlit/secrets.toml`이 등록되어 깃허브로 앱 비밀번호가 유출되지 않는지 확인해 주세요.)*

---

### Step 3. 코드에 이메일 발송 기능 반영

설정이 끝나면 `sheet_manager.py`에 메일 전송 공통 함수를 넣고, `student_app.py`와 `admin_app.py`에서 함수를 호출하도록 코드를 수정하시면 됩니다.

준비가 되셨다면 세 파일의 수정 코드를 바로 적용할 수 있도록 정리해 드릴까요?
